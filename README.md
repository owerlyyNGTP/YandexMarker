# Яндекс.Метка

Веб-приложение на Flask для создания и управления метками на Яндекс.Картах.

## Возможности

- 🔐 Регистрация и авторизация пользователей
- 📍 Добавление меток с фото и описанием
- 🗺️ Отображение меток на карте с кластеризацией
- 📁 Загрузка GPX-треков и отображение на карте
- ☁️ Интеграция с API Яндекс.Погоды (в разработке)
- 👑 Админ-панель для управления пользователями

## Технологии

- Python 3.13
- Flask + SQLAlchemy + Flask-Login
- SQLite
- Яндекс.Карты API 2.1
- Bootstrap (Flask-Bootstrap)
